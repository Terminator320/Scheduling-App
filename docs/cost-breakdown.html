What the 21 Cloud Functions actually cost

Across every function, trigger, and supporting service, the backend runs almost entirely inside Google's free tiers — a realistic ~$0.30/month (six Cloud Scheduler jobs, only three free), with a ceiling near $5. No function's compute is a lever. Two Google Maps Platform SKUs scale cost: Places autocomplete (bills per keystroke) and the Routes API the travel-time reminder sweep now calls (~13–16 calls per job as it approaches, ledger-capped once fired). Both sit under their 10K-free-per-SKU monthly caps at this business's volume (a busy 20-jobs/day month is ~9.6K Routes calls).

Scenarios

How the total moves as the shop grows. The two numbers that change are the Maps Platform SKUs — Places autocomplete (per keystroke) and the Routes API the leave-now sweep calls (per job as it approaches).

!

The one guardrail worth setting: a GCP Maps Platform billing alert covering both placesAutocomplete and the Routes API. Places' in-code rate limit is per-instance, not a hard cap, and it fires once per keystroke while an address is typed; both Places proxies are now admin-only (server-side assertAdmin), so only a trusted admin session can drive that spend. The Routes API is called server-side by the leave-now sweep (never from the app) and is ledger-capped to fire once per job, so its spend scales only with job volume. The sweep also memoizes each drive-time estimate for ~10 minutes, so a job waiting out its 90-minute window is priced a couple of times rather than on all ~18 sweeps — a cached estimate can only defer a call, never trigger a send. The single alert backstops both APIs.

Basis & assumptions

  • Pricing: 2025 public Blaze-plan rates, us-central1 / North America. Rates change; treat as ballpark.
  • Scale modeled: 3 admins / 8 employees, ~700 clients, ~900 appointments/mo, ~50% needing a new address lookup, ~1.5 photos/appointment.
  • Free tiers cited: Functions 2M invocations + 180K vCPU-s; Places 10K calls per SKU; Firestore 50K reads / 20K writes / 20K deletes per day; Storage 5 GB; Scheduler 3 jobs (six now run, so three bill at $0.10/job); FCM push unlimited & free; Secret Manager 6 versions + 10K access.
  • Google Places replaced its $200 monthly credit (March 2025) with a per-SKU free monthly cap; session tokens can bill in-session autocomplete as $0.
  • Wave Accounting, Firebase Cloud Messaging, and Apple's APNs (which carries the iOS Live Activity card) charge nothing per call — those functions cost only their (free-tier) Firebase compute.
  • All 21 functions are wired in functions/index.js for schedulingapp-88727; counts reflect the source as of 2026-07-19.
